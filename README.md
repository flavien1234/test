# Morpion

Jeu du morpion (tic-tac-toe) en HTML/CSS/JS, sans dépendance.

- Mode **contre l'ordinateur** (Facile, Moyen, Imbattable — algorithme minimax)
- Mode **2 joueurs** sur le même écran
- Compteur de scores, le premier joueur alterne à chaque partie

Pour jouer en local : ouvrir `index.html` dans un navigateur.

Le site est déployé sur GitHub Pages par le workflow `.github/workflows/pages.yml` à chaque push sur `main`.
